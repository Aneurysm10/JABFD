# Main Duck - discord.py bot
<span style="font-weight: normal;">Main Duck is a multipurpose Discord bot developed using discord.py. The project is still in its early stages and may contain bugs.</span>

---

# Technologies

* **Python 3.13** — Core programming language
* **discord.py 2.7.1** — Discord API wrapper
* **SQLAlchemy** — Database ORM and asynchronous database operations
* **PostgreSQL** — Database management system
* **Alembic** — Database migrations
* **python-dotenv** — Environment variable management
